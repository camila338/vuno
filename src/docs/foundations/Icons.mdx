## Usage

- `-outline` by default; the filled version of the same icon when active or selected.
- An icon takes the color of the text it sits with (`color.text.*`, `.fg` or `on-accent`).
- An icon without text needs an accessibility label, and its touch target is `size.touch.min` (48) even if the icon is 24.
- Back, more and share follow each platform (see Platforms): `useSystemIcon()`.
