## Usage

- The display face is only for `balance` and `headline`, never for paragraphs, buttons or labels.
- One `balance` per screen.
- Amounts in lists use tabular figures (`fontVariant: ['tabular-nums']`) so they line up.
- In React Native each weight is its own family: a role points to the instance, not to `fontWeight` (Android ignores it with custom fonts).
- On Android, `includeFontPadding: false` so line heights match iOS.
- Text never goes below 12 px and every line height is a multiple of 4.
- The system text size is honored up to 200% for `body`; the balance caps at 1.5× (`maxFontSizeMultiplier`).
