## Criteria

- **Contrast:** 4.5:1 for body text; 3:1 for large text (24 px or more, or 18.66 px bold), icons, control boundaries and focus. Disabled elements are exempt.
- **States:** color is never the only signal. Chips carry an icon and errors carry text.
- **Scaling:** the system text size is honored up to 200% for `body`.
- **Motion:** Reduce Motion is honored.
- **Screen readers:** VoiceOver (iOS) and TalkBack (Android). Amounts are read in full (“1050 dollars and 77 cents”).

## Do's and Don'ts

<DoDont>
  <Do caption="An error with a border, an icon and text.">
    <Live width={280}><TextField label="Account number" value="1234" error="Add the missing digits" onChangeText={() => {}} /></Live>
  </Do>
  <Dont caption="An error shown only with a red border: people who don't perceive the color miss it.">
    <Live width={280}>
      <Text variant="label">Account number</Text>
      <View style={{ minHeight: tokens['input.height'], borderRadius: tokens['input.radius'], borderWidth: 1, borderColor: tokens['input.error.border'], backgroundColor: tokens['input.bg'], justifyContent: 'center', paddingHorizontal: tokens['space.md'] }}><Text>1234</Text></View>
    </Live>
  </Dont>
</DoDont>

<DoDont>
  <Do caption="A chip with an icon and text.">
    <Live width={240} center><Chip status="warning" label="Low balance" /></Live>
  </Do>
  <Dont caption="A status shown only as a colored dot.">
    <Live width={240} center><View style={{ width: tokens['space.sm'], height: tokens['space.sm'], borderRadius: tokens['radius.pill'], backgroundColor: tokens['color.status.warning.fg'] }} /></Live>
  </Dont>
</DoDont>
