## Usage

<ul>
  <li>One <code>primary</code> button per screen; the rest are <code>secondary</code> or <code>tertiary</code>.</li>
  <li>Width follows the content. Use <code>fullWidth</code> only for the main action at the bottom of a screen.</li>
  <li>Labels of 1 to 3 words that start with a verb, in sentence case: “Continue”, “Send money”.</li>
  <li>8 pt (<code>space.xs</code>) between adjacent buttons. The heavier one goes on the right or on top.</li>
  <li>When the action takes time, use <code>loading</code>: the button keeps its width and blocks a second tap.</li>
</ul>

## Accessibility

<ul>
  <li>The visible label is the name VoiceOver (iOS) and TalkBack (Android) read; no separate <code>accessibilityLabel</code> is needed.</li>
  <li>Use <code>accessibilityHint</code> when the result isn't obvious (“Opens the transfer flow”).</li>
  <li>Minimum height of 48 (<code>size.touch.min</code>): it meets iOS's 44 pt and Android's 48 dp, tertiary included.</li>
  <li>Disabled and loading are announced through <code>accessibilityState</code>.</li>
</ul>

## Do's and Don'ts

<DoDont>
  <Do caption="Use 1 to 3 words that start with a verb."><Live width={300} center><Button label="Continue" onPress={() => {}} /></Live></Do>
  <Dont caption="Long labels get cut off on a phone."><Live width={300} center><Button label="Continue to the next step" onPress={() => {}} /></Live></Dont>
</DoDont>

<DoDont>
  <Do caption="Primary for the main action, tertiary as the alternative."><Live width={300} center><Row><Button kind="tertiary" label="Cancel" onPress={() => {}} /><Button label="Confirm" onPress={() => {}} /></Row></Live></Do>
  <Dont caption="Two primary buttons side by side compete for attention."><Live width={300} center><Row><Button label="Cancel" onPress={() => {}} /><Button label="Confirm" onPress={() => {}} /></Row></Live></Dont>
</DoDont>

<DoDont>
  <Do caption="Use sentence case."><Live width={300} center><Button label="Get started" onPress={() => {}} /></Live></Do>
  <Dont caption="Don't use all caps or Title Case."><Live width={300} center><Button label="GET STARTED" onPress={() => {}} /></Live></Dont>
</DoDont>

<DoDont>
  <Do caption="Use verbs that say what happens on tap."><Live width={300} center><Row><Button kind="tertiary" label="Cancel" onPress={() => {}} /><Button label="Send money" onPress={() => {}} /></Row></Live></Do>
  <Dont caption="Generic labels like Yes / No force people to read the whole context."><Live width={300} center><Row><Button kind="tertiary" label="No" onPress={() => {}} /><Button label="Yes" onPress={() => {}} /></Row></Live></Dont>
</DoDont>
