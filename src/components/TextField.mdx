## Usage

<ul>
  <li>The label sits outside the field and stays while typing; the placeholder is an example.</li>
  <li>Show the error when leaving the field or on continue, not while typing.</li>
  <li>The error message says how to fix it.</li>
  <li>Use the right keyboard (<code>keyboardType</code>) for emails, numbers or amounts.</li>
</ul>

## Accessibility

<ul>
  <li>The label is the field's name for VoiceOver and TalkBack.</li>
  <li>The border (<code>border.input</code>) is 4.90:1 on the card (WCAG 1.4.11).</li>
  <li>The error doesn't depend on color: it has an icon and text.</li>
</ul>
