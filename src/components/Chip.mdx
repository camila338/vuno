## Usage

<ul>
  <li>Always an icon and text: color never goes alone.</li>
  <li>One to three words.</li>
  <li><code>highlight</code> only for positive milestones, such as reaching a goal. One per screen.</li>
  <li>Not tappable: to pick options, use <code>ChoiceChip</code>.</li>
</ul>

## Accessibility

<ul>
  <li>Read as text; the icon is decorative and the text carries the meaning.</li>
  <li>Every text/background pair passes AA (FOUNDATIONS §11).</li>
</ul>
