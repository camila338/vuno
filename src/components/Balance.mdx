## Usage

<ul>
  <li>One per screen; every other amount uses <code>headline</code> or <code>body</code>.</li>
  <li>The label says what the figure is.</li>
</ul>

## Accessibility

<ul>
  <li>VoiceOver and TalkBack read the label and the full figure: “Label: 1250 dollars and 50 cents”.</li>
  <li>Scales with the system text size up to 1.5×.</li>
</ul>
