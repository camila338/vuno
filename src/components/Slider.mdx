## Usage

<ul>

  <li>Always show the chosen value as text.</li>
</ul>

## Accessibility

<ul>
  <li>Announced as adjustable: with VoiceOver, swipe up or down; with TalkBack, use the volume keys.</li>
  <li><code>valueText</code> is what gets read (“6 months”), not the bare number.</li>
</ul>
