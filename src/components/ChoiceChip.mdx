## Usage

<ul>
  <li>Single choice among 2 to 6 short options. With more, use a list.</li>
  <li>Options wrap onto new rows.</li>
  <li>One tap selects; no confirm button needed.</li>
</ul>

## Accessibility

<ul>
  <li>Announced as a button with its selected state.</li>
  <li>A 48 height (<code>chip.choice.height</code>).</li>
</ul>

## Do's and Don'ts

<DoDont>
  <Do caption="Few, short options."><Live width={300} center><Row><ChoiceChip label="Weekly" onPress={() => {}} /><ChoiceChip label="Monthly" selected onPress={() => {}} /></Row></Live></Do>
  <Dont caption="Too many options: use a list."><Live width={300} center><Row>{["One","Two","Three","Four","Five","Six","Seven","Eight"].map((o) => <ChoiceChip key={o} label={o} onPress={() => {}} />)}</Row></Live></Dont>
</DoDont>

<DoDont>
  <Do caption="One selected option in a single choice."><Live width={300} center><Row><ChoiceChip label="Weekly" onPress={() => {}} /><ChoiceChip label="Monthly" selected onPress={() => {}} /></Row></Live></Do>
  <Dont caption="Several selected: it's unclear what was chosen."><Live width={300} center><Row><ChoiceChip label="Weekly" selected onPress={() => {}} /><ChoiceChip label="Monthly" selected onPress={() => {}} /></Row></Live></Dont>
</DoDont>
