## Usage

<ul>
  <li>Only with universally understood icons; if the icon needs explaining, use a <code>Button</code> with text.</li>
  <li>Back, more and share use each platform's system icon: <code>useSystemIcon('back')</code>.</li>
  <li>In a top bar: on the start side to go back or close, on the end side for more options.</li>
  <li>Two or three at most in the same bar.</li>
</ul>

## Accessibility

<ul>
  <li><code>label</code> is required: it's what VoiceOver and TalkBack read (“Back”, “Close”).</li>
  <li>A 48 diameter (<code>button.circle.size</code>): the full touch target.</li>
</ul>

## Do's and Don'ts

<DoDont>
  <Do caption="Icons everyone recognizes."><Live width={300} center><IconButton icon="close" label="Close" onPress={() => {}} /></Live></Do>
  <Dont caption="Ambiguous icons: nobody knows what they do."><Live width={300} center><IconButton icon="planet-outline" label="Settings" onPress={() => {}} /></Live></Dont>
