## Usage

<ul>
  <li>2 to 5 sections with one-word labels.</li>
  <li>Each item uses a filled icon; the inactive one uses its <code>-outline</code> version.</li>
  <li>It takes its own space: content never shows underneath.</li>
</ul>

## Accessibility

<ul>
  <li>Announced as a tab list with the selected state.</li>
  <li>Each item is at least 48 tall.</li>
</ul>
