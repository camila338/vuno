## Usage

<ul>
  <li>Flat: a border and no shadow. Shadows are only for what floats (FOUNDATIONS §5).</li>
  <li>Accent only for a product summary, inside its <code>VerticalProvider</code>.</li>
  <li>Text on the accent uses the same vertical's <code>on-accent</code>.</li>
  <li>Don't nest a card inside another.</li>
</ul>

## Accessibility

<ul>
  <li>A card isn't tappable by itself; if it leads to another screen, use a <code>ListRow</code> or a button inside.</li>
  <li>Every accent / on-accent pair passes AA.</li>
</ul>
