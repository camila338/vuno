## Usage

<ul>
  <li>Always with the figure above it, updating on every key.</li>
  <li><code>applyKey</code> applies a key and caps the number of digits.</li>
  <li>The continue action sits below and enables once there is an amount.</li>
</ul>

## Accessibility

<ul>
  <li>Each key is a button with its digit; delete is announced as “Delete”.</li>
  <li>Keys are 48 tall plus their spacing.</li>
</ul>
