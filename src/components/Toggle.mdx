## Usage

<ul>
  <li>Immediate effect. If the change needs confirming, use a button.</li>
  <li>Always in a row with a title and one line explaining what turning it on does.</li>
</ul>

## Accessibility

<ul>
  <li><code>label</code> is required: VoiceOver and TalkBack announce it as a switch with its state (“Label, switch, on”).</li>
  <li>The disabled state is announced automatically.</li>
</ul>
